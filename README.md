# JavaScript Asynchronous Patterns

This repository contains examples of handling asynchronous operations in JavaScript using:

1. **Callback**  
2. **Promise**  
3. **Async/Await**

## Structure

- **callback/** → Example using callbacks.
- **promise/** → Example using Promises.
- **async-await/** → Example using async/await.

## How to Run

1. Open the `index.html` file in your browser.
2. Open the browser console (F12) to see the output.
3. Each folder demonstrates the same problem:  
   - Fetch numbers `[1,2,3,4,5,6,7,8]`  
   - Multiply by 2  
   - Sum the numbers
